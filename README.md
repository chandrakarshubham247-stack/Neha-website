# Neha's Little Box — Premium 3D Website

A premium, agency-style gifting website concept with:
- Cinematic 3D Three.js hero scene
- Gifty Moments storytelling section
- Product collection + bestseller UI
- Custom gift request flow
- Luxury responsive mobile design
- Mouse parallax, tilt cards, scroll reveals and micro-interactions

## Run
Open `index.html` in a browser. It uses Google Fonts and Three.js from CDNs, so internet is needed for those assets.

## Before launch
Replace demo visuals with real product photos, add the actual WhatsApp number, connect the form to WhatsApp/email/backend, and add real prices/social links.

## Free deploy
Upload the folder to Cloudflare Pages, Netlify, Vercel, or GitHub Pages.
